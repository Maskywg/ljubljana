# 盧比亞納城市走讀

以「不斷被摧毀、重建、重新定義的城市」為題的繁體中文旅遊網站。

包含歷史年表、13 站互動走讀地圖、建築與雕像故事、拍照建議及 Plečnik 專章。

## 編輯與預覽

網站原始檔位於 `dist/`。`index.html` 為內容、`style.css` 為樣式、`app.js` 為互動、`stops.js` 為地圖景點資料。

可用 `python3 -m http.server 8873 --directory dist` 預覽。GitHub Pages 從 `main` 分支的 `dist/` 目錄發布網站。

## 來源與授權

官方資料來源、照片作者與 Creative Commons 授權均列於網頁末端。照片使用時請保留相應署名及授權。Leaflet 授權位於 `dist/assets/leaflet-LICENSE.txt`；地圖資料由 OpenStreetMap contributors 提供。
